## What this project is

The **M11NTX storefront** — a fast, dependency-free site (vanilla HTML5 / CSS3 /
ES6, no frameworks, no build step) deployed on **GitHub Pages**. Premium soccer
(jersey) culture, dark/gold identity.

- This repo: `collection-site` → https://github.com/m11ntx/collection-site
- Data pipeline (separate): `../catalog-pipeline` →
  https://github.com/m11ntx/catalog-pipeline (generates `data/*.json` + images).
- The two communicate through **one contract only: the JSON in `data/`**.

Architecture:
```
data/*.json → api.js → catalog.js → ui.js → screen
```

---

## Pages & navigation

```
Landing (index.html)
  → Collection detail  (pages/collection.html?slug=…)
    → Club             (pages/club.html?slug=…)
      → Jersey         (pages/jersey.html?slug=…)
```

- **index.html** — fixed nav (revealed on scroll), mobile menu, search overlay
  (layout only), the **frozen hero/landing**, and the **Collections** grid
  (rendered from JSON).
- **pages/collection.html** — banner + clubs of a collection (reads `?slug=`).
- **pages/club.html** — club crest/league + jersey grid (reads `?slug=`).
- **pages/jersey.html** — premium gallery (swap/fade/zoom, no libs), specs
  (brand/type/category/season/version/gender), sizes + stock, **Comprar na Feng**.
- Subpages reuse the nav/footer via `<base href="../">`.

## JavaScript layers (`assets/js/`)

## How to run

Uses `fetch()`, so serve over HTTP (not `file://`):

```bash
python -m http.server 8000     # then open http://localhost:8000
```

GitHub Pages serves it over HTTP automatically.

## Key decisions (do not re-derive)

- **The hero / landing is FROZEN** — approved design; do not restyle it.
  Also treat as approved: navbar, footer, Collections grid, design system, palette.
- **JSON is the single source of truth** — never hardcode catalog data.
- Subpages use `<base href="../">` so all paths resolve from the site root.
- Availability: a jersey is out of stock when no size has stock; the buy button
  disables and an **Out of Stock** badge shows (mirrors pipeline RN-006/RN-007).
- `buyUrl` values are **placeholder** Feng search URLs — to be replaced with real
  product links (the pipeline will populate them).
- Brand assets are generated by `scripts/gen/apply_assets.py` from the originals
  in `assets/images/Novas/`; favicon pack in `assets/icons/`.
