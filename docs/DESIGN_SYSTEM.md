## Marca / Ícones

Símbolo oficial: monograma "M11" dourado (arquivos oficiais em
`assets/images/Novas/`).

Assets de produção (gerados a partir dos oficiais):
- `assets/images/logo-horizontal.png` — wordmark M11NTX (fundo removido)
- `assets/images/hero-background.webp` / `.jpg` — tecido escuro
- `assets/images/escudo.png` — escudo de couro (fundo removido)
- `assets/images/symbol.png` — marca M11 isolada (rodapé)
- `assets/icons/` — favicon.ico (16/32/48), favicon-16/32/48.png,
  apple-touch-icon.png (180), android-chrome-192/512.png, site.webmanifest

Para regenerar tudo a partir dos oficiais:
`cd scripts/gen && python apply_assets.py`
